# Task Tracker

A task management desktop app built with Python.

## Features
- Add tasks with priority and deadline
- View all tasks
- Mark tasks as complete
- Filter tasks by status or priority
- Delete tasks
- Data stored persistently using SQLite database

## Tech Stack
- Python
- Tkinter (GUI)
- SQLite3 (Database)

## How to Run
1. Make sure Python is installed
2. Clone this repository
3. Run the file:
   python task_manager.py

## Why I Built This
Built this project to understand task tracking and 
project coordination at a technical level — relevant 
to program management and operational roles in tech companies.
